## Failed-gate evidence

Release run `33673803471`, Archive V2 job `100393542870`, advanced through the
four-validator hot/cold Archive V2 matrix and entered the strict DEX journey.
The volume journey reported 138 passes and six failures. The failures were
pair-1 order simulations returning DEX Core ABI code 11 in the first trading
phase: Carol/Dave at 0.11, Eve/Alice at 0.115, and Bob/Carol at 0.108. The first
Alice/Bob match at 0.105 and the final Dave/Eve match at 0.112 succeeded. Later
CLOB depth, multi-pair, AMM, margin, prediction, governance, rewards, router,
analytics, and WebSocket checks proceeded successfully.

Setup had already proved trader balances and token approvals. DEX Core code 11
can represent either an unavailable/stale price band before escrow or an escrow
failure. The timing pattern, successful surrounding orders, and successful
later explicit quorum refresh isolate the observed failure to the price-band
freshness boundary rather than missing allowance or insufficient balance.

## Root cause

DEX Core intentionally rejects orders when the canonical pair price band is
more than 750 slots old. The hosted four-validator chain advances quickly. The
journey performed roughly 65 setup cancel transactions across five wallets and
13 pairs before pair-1 trading, consuming about 32 seconds without establishing
a new controlled band. Whether the existing band remained valid therefore
depended on runner slot throughput and incidental periodic refresh alignment.

This is a release-harness readiness race, not evidence that Archive V2 changed
DEX settlement. The production contract behaved correctly by failing closed.
A production oracle updater that stops for more than the configured freshness
window will intentionally halt affected orders; that is a safety property that
must remain monitored on both fresh networks and mainnet.

## Narrow correction

- Immediately before phases 1, 2, and 3, submit the controlled LICN/USD quote
  from every active local validator through the native consensus oracle path.
- Read back both the DEX Core band and margin mark and require equal non-stale
  source slots.
- Require at least two active validator attestations before trading.
- Keep the 750-slot maximum age and all contract rejection logic unchanged.
- Add static release QA proving the refresh occurs after setup cancellation and
  before each pair-1 CLOB phase.

The controlled reference is 0.106 fixed9. Its existing ±50% DEX band covers the
strict journey's phase-1 and depth prices. Each phase refreshes independently so
one long test phase cannot silently lend stale readiness to the next.
