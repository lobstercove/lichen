## Correction

The canonical MossStake decoder is split into structural decoding and strict
accounting validation. Ordinary/local snapshot imports retain strict validation.
Only the already authenticated network checkpoint staging path may preserve a
structurally canonical legacy pool long enough to verify the complete checkpoint
manifest and state root before atomic live-state activation.

After EU converges from that exact checkpoint, all four validators must stop at
the same tip. The signed validator provides
`--repair-legacy-testnet-mossstake-accounting` with these boundaries:

- exact chain ID `lichen-testnet-1`; fresh testnets and mainnet refuse;
- the durable slot-only MossStake activation marker must already be present;
- exclusive RocksDB open, requiring the validator process to be stopped;
- exact embedded stale owner, position fields, and pending-exit fields;
- exactly one zero-share row and no repair of any unknown accounting shape;
- maximum 1,000,000-spore rounding remainder;
- deterministic assignment of the remainder to the lexicographically final
  positive-share position, matching MossStake's existing reward-remainder rule;
- dry-run projection before any write;
- required expected tip, tip block hash, before/after state roots,
  before/after MossStake hashes, expected remainder, and derived confirmation;
- atomic pool write, strict post-write invariant validation, current-tip
  post-state anchor update, durable idempotency marker, and synchronous WAL; and
- safe completion if interruption occurs after the pool write but before the
  anchor or marker write.

The pending exit, stLICN total supply, active backing, exchange-rate formula,
and all positive-share principal remain unchanged. No unavailable historical
block is fabricated.

The tagged deployment helper now also uses systemd's supported
`--kill-who=all` selector for validator, custody, faucet, and Moss bounded-kill
fallbacks. `v0.5.277` required a hash-verified operational copy because it
passed the unit `KillMode=control-group` value to a command that accepts only
`all`, `main`, or `control`.
