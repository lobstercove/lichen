# v0.5.267 Production-Readiness Addendum

Date: 2026-09-01

Status: candidate for protected CI and the immutable tag workflow. This is not
an installable release, a live deployment approval, or a mainnet approval until
the exact tag produces provenance-attested artifacts and detached ML-DSA-signed
checksums and the coordinated live testnet acceptance gates pass.

## Corrective scope

Immutable `v0.5.266` passed formatting, strict Clippy, workspace and standalone
tests, dependency policy, and the substantive release gates before failing
closed in `Verify release policy assets`. On the clean runner, five wallet
secret-boundary tests could not import `sdk/js/dist/keypair` because the release
quality job installed and audited the JavaScript SDK but did not build it.
Local generated output had masked that release-only ordering defect. The failed
tag published no installable assets and is not rewritten or reused.

`v0.5.267` preserves the reviewed runtime from the
[v0.5.266 production-readiness review](V0.5.266_PRODUCTION_READINESS_2026-09-01.md).
Its only behavioral correction is to build the JavaScript SDK after its clean
install and dependency audit and before wallet audits. A tracked GitHub Actions
QA assertion now fails if install, build, and wallet-audit ordering regresses.

## Qualification and release boundary

The focused local gate must reproduce the clean-runner precondition with no
`sdk/js/dist`, execute the release workflow's install/audit/build sequence, and
pass the complete wallet audit plus workflow, public-claim, frontend, exchange,
and version-consistency QA. The protected branch and tag workflows remain the
authoritative full gates and must independently repeat all Rust, contract,
Archive V2, frontend, wallet, SDK, provenance, and four-validator checks.

No validator may install a local build. Preserve `v0.5.265` as the signed
rollback anchor and preserve every validator's identity, keys, WAL, hot state,
legacy archive, source configuration, and signed evidence. Deployment remains
a coordinated stop/install/start from one verified Linux workflow artifact.

Archive V2 activation, signed range-bound legacy retirement, four-way logical
genesis-to-tip parity, stable cadence, and any R2 deletion retain their separate
live gates. In particular, this addendum authorizes no R2 deletion.
