Date: 2026-08-29

Status: locally qualified corrective candidate. Hosted protected-branch and
tag-workflow qualification remain mandatory. Not signed, not released, not
deployed, and not approved for mainnet.

## Trigger

Immutable tag `v0.5.264` resolved to protected-main commit
`30def3b90cdc4947e5a662e7b40d4b69a043a85d`. Release workflow run
`33244099890` passed its quality/security, genesis-contract,
compiler-sandbox, and tagged binary-build prerequisites, then failed closed in
four-validator job `99086724326`. No release assets or signatures were
produced.

The accelerated four-validator cluster was healthy and advancing, but both
observed Archive V1-to-V2 migrations paused with
`cpu_pressure:load_one=8.54:cpus=4`. Every colocated validator read the same
Linux host-wide load average and independently applied the production
single-validator threshold. The harness correctly rejected the absence of
independently advancing durable migration after 180 seconds. macOS does not
compile the `/proc/loadavg` branch, so the earlier clean local qualification
could not expose this Linux-only integration boundary.

## Correction boundary

`host_cpu_pressure_reason` now omits only the host-wide load-average decision
when explicit `LICHEN_LOCAL_DEV` mode is enabled. That mode already substitutes
a production cadence for the accelerated consensus-latency pressure check.
Disk headroom, memory pressure, consensus staleness, observed cadence, and
Archive V2 capacity checks remain active in local development. All production
validators retain the original `load_one > available_parallelism` fail-closed
behavior.

Platform-independent unit coverage fixes the exact 8.54/four-CPU regression,
the production equality and over-threshold boundaries, the local-dev boundary,
and the zero-CPU fallback.

Qualification also found a separate release-bundle inventory defect: the
canonical contract builder rebuilt 33 workspaces while the release workflow
staged all 34 tracked WASMs, leaving the standalone `mt20_token` template stale.
The builder now owns all 34 workspaces, offers an explicit template scope, and
release QA fails if any in-tree contract workspace is absent. A clean rebuild
changed `mt20_token.wasm` from 20,412 to 21,043 bytes; a second clean release-
gate build reproduced SHA-256
`f568cd03a9ff0a2f0b5fc09ebb80adee47fdb9306618d4a4a473a9c994c59124`.
