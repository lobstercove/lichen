`7a016d0dcdfdc1d2e86a0855866c4c36ed63d247`. Both bounded attempts failed
closed in the four-validator Archive V2 job before platform builds, release

The attempts passed the substantive checks reached before their failure,
including four-way logical public-history manifest parity, deterministic

own-state restart, coordinated restart, BFT entry, and continuing block
production. The first attempt timed out observing all four finalized RPC
frontiers after the intentional V4 corrupt-segment restart. The second attempt
repeated the same observation failure after initial role admission: individual

The gate queried each validator's processed and finalized slots serially. A
transient timeout or readiness refusal could consume five to eight seconds per
node, so the 180-second global window contained only a few complete snapshots
and required all eight RPC reads to succeed in one serial pass. A third blind
rerun is not evidence-based and is prohibited.

## Narrow correction

`getHealth` now includes `finalized_slot`, sourced from the same live finality
tracker or durable fallback used by the existing finalized-slot RPC. Health is
the deliberately always-available readiness surface and already publishes the
processed slot.

The four-validator gate now probes all validator health records concurrently.
Each probe has bounded retries and validates `status=ok`, positive integer
processed/finalized slots, and `finalized_slot <= slot`. The existing maximum
cross-validator finalized spread and maximum processed-to-finalized lag checks
are unchanged. This removes serial observation starvation; it does not accept
stale, missing, non-finalized, or divergent state.

Focused qualification currently includes Bash syntax, the tracked Archive V2
asset gate, formatting, and the RPC readiness regression. Full workspace,
standalone, security, contract/genesis, frontend/deployment, exact clean
four-validator, protected CI, tag, signature, artifact, coordinated deployment,
live parity, and disk-reclamation gates remain mandatory.

No validator may install a local build. Preserve signed `v0.5.265` as the sole
immediate rollback anchor and preserve every validator identity, key, WAL, own
chain state, archive source, access configuration, and signed evidence. This
addendum authorizes no R2 deletion or mainnet deployment.
